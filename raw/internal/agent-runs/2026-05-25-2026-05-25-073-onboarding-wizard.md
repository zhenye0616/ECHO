# 073 - Onboarding Wizard (Run 1)

## What I implemented

Implemented the UX-free onboarding wizard library for steps 2-5 of `echo init`.
The branch adds staged APIs for agent detection, project detection, adapter
cache IO, ECHO-section rendering, wiring through 072's `syncAll`, best-effort
agent probes, and the top-level `createWizard()` facade that 074 can drive.

The daemon DB-path resolver was promoted from `src/daemon/index.ts` into
`src/daemon/lifecycle.ts` so wizard production reads mirror daemon path
precedence exactly: `ECHO_DB_PATH` > `ECHO_DATA_DIR` > default app-support DB.

## Decisions made during implementation

1. **Readonly atom-store adapter implements only `query`.** Production uses
   `better-sqlite3` with `{ readonly: true, fileMustExist: true }` and
   `PRAGMA query_only = ON`. Non-query `Storage` methods throw a wizard-scope
   error, keeping AC1/AC2 reads from creating or migrating the daemon DB.
2. **Agent activity uses the canonical `buildSourceAppMap()` prefixes.**
   `detectAgents()` maps `codex`, `claude-code`, and `cursor` into canonical
   source apps and queries by `source_prefix` over the 30-day window with the
   50,000-row saturation flag.
3. **Project grouping canonicalizes repo roots by resolved path.**
   `detectProjects()` merges trailing-slash variants and ranks by activity,
   returning the requested top-25 default with source breakdowns.
4. **`wire()` treats 072 top-level sentinels as non-mutating failures.**
   `syncLock`, `repoRoot`, and `directorySymlink` failures do not write cache
   files or onboarding state. Successful agent results refresh per-agent cache
   and onboarding profiles.
5. **Probe remains best-effort and cursor is manual-only.** Codex and
   Claude Code spawn headless commands and parse the last stdout JSON line;
   Cursor returns the documented manual-only result.
