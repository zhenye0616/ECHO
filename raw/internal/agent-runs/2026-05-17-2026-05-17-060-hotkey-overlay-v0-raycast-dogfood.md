# Agent Run: V0 hotkey overlay — Raycast extension for founder dogfooding

## What I Implemented

Built `tools/raycast-echo/`, a local Raycast extension with one view command, `Search ECHO Context`.

The command renders a two-state Raycast List: empty input calls `find_clusters()`, typed input debounces for 200ms and calls `search_memories({ query, limit: 15 })`. Detail panes hydrate via `get_atoms` for cluster rows and `get_atom` for search-match rows. The action panel implements the row-specific AC2 shape: cluster rows expose Copy, Paste, and Open Trace Viewer; search-match rows expose Copy, Paste, Open Source, Open Trace Viewer, and Copy Raw Atom JSON.

## Decisions Made During Implementation

### Decision 1: Use the spec's fetch fallback for MCP

- **Options considered:** Raycast-bundled MCP SDK client transport vs. direct JSON-RPC `fetch`.
- **Chose:** Direct JSON-RPC `fetch`.
- **Why:** The spec explicitly allows this fallback under R1 if SDK bundling is risky. The extension still declares `@modelcontextprotocol/sdk` as required, but the runtime client stays small and sends the daemon-required `Content-Type: application/json` plus `Accept: application/json, text/event-stream` headers.
- **Worth founder review?** No. This follows the spec's risk mitigation.

### Decision 2: Do not commit Raycast-generated type output

- **Options considered:** Commit `raycast-env.d.ts` generated by `npx ray build` vs. remove it after verification.
- **Chose:** Remove it after build.
- **Why:** It is generated from `package.json`, not listed in `files_to_modify`, and the source typechecks without it.
- **Worth founder review?** No.

### Decision 3: Keep Vitest scoped to the extension

- **Options considered:** Let Vitest auto-discover the repo-root config vs. pass `--config ./package.json` in the extension script.
- **Chose:** `vitest run --config ./package.json`.
- **Why:** Auto-discovery walked up to the root config and tried to load root-only dependencies from the extension install. The required AC5 test is pure Node and should be self-contained under `tools/raycast-echo/`.
- **Worth founder review?** No.
