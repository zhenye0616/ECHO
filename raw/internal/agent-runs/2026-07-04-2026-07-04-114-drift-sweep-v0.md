## What was implemented

The clocked understanding-drift detector (seam decisions 14-16, 20; loop-gap station 6).

- **AC1 — clocked worker + durable append-order cursor.** New `startDriftSweepWorker`
  registered inside `startEnrichmentDispatch`, chained after the granola signal worker via
  `runSignalsFirst` (interval + single-flight). Each tick reads
  `getSignalWindow({cursor:{sinceSeq: watermark}, scope:'company'})`. The watermark is a
  durable `sequence_id` persisted via `atomicWrite`. It advances to `min(blocking statement
  seq)` when any statement is non-terminal, else `max(window seq)+1`. Late-ingested atoms get
  a HIGHER sequence_id (append order), so they are never skipped.
- **AC2 — the join.** New `derived:granola-signals` statements (types decision/rationale/action)
  joined against the latest team decision per subject by exact `canonical_subject` equality.
  No-match statements skipped silently (never reach the judge).
- **AC3 — idempotent judge.** Per (decision dedupe_key, statement dedupe_key, judge version)
  pair, judged at most once ever (checkpoint file, granola-signals pattern; atomic pre-delivery
  write). Strict-JSON runBrain verdict {contradicts, quote, reason}. Shared budget
  `DRIFT_JUDGE_MAX_ATTEMPTS=3` for malformed parse + non-verbatim quote (AC4). Retryable infra
  errors (`DriftJudgeInfraError`) are NOT counted and leave the pair unjudged (blocks watermark,
  retried next tick). Terminal-judge-failed records durable operator-visible evidence
  (checkpoint entry + `log.error drift_judge_failed` with pair keys, judge version, reason,
  attempts).
- **AC4 — code-enforced faithfulness.** `quoteAppearsVerbatim` (code check, not prompt):
  verdict.quote must be a substring of the statement atom content, else discarded + logged
  `drift_verdict_rejected`, counted against the shared budget → terminal-judge-failed after MAX.
- **AC5 — owner alert, at-most-once.** On a surviving contradiction, DM the decision owner
  (`confirmed_by` → `cofounderIdToSlackUserId`) a Block Kit card (decision + confirmed_at/by,
  contradicting quote, meeting provenance, Acknowledge/Dismiss buttons whose value = pair key),
  posted daemon-side (postGranolaIntakeSeed pattern, no Socket Mode). Delivery guarded by
  per-pair checkpoint: intent-before-post, outcome-after; ambiguous crash → `delivery-failed`
  next tick with no re-post. Buttons handled in responder.ts (`extractDriftAction` +
  `respondToDriftAction`, new `echo_drift_*` block_actions branch); dismissals append to
  `ceo-loop-events.md` as noise signals (`appendDriftDismissalRecord`).
- **AC6 — fail-closed + blast-radius cap.** OFF by default behind `ECHO_DRIFT_SWEEP_ENABLED`;
  enabled-but-misconfigured (no Slack token / no identities) → disabled handle carrying a
  structured `DriftSweepConfigError`, never a crash. `maxAlertsPerTick` (default 3) caps
  deliveries; overflow → `delivery-deferred` (non-terminal), logged not posted, drains on later
  ticks without re-posting.

Terminal-state set is total: judged-no-contradiction, terminal-judge-failed, delivered,
delivery-failed (all terminal); delivery-deferred, delivery-intent (non-terminal, hold the
watermark). no-match statements never create a pair.
