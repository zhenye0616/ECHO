## Decisions made during implementation

1. **TOML header detection allows inline `# comment`.** Per TOML, table
   headers may be followed by whitespace + a `# comment`. The byte-range
   slice-end scan in `codex-config.ts` recognizes this so that
   `[projects.foo] # inline comment` correctly terminates the
   `[mcp_servers.echo]` slice. (AC2 case 2 + 9 pin this.)
2. **`atomic-write.ts` exports a `__setAtomicWriteTestHook(hook)` test-only
   surface.** Required because `vi.spyOn` cannot mock node ESM namespace
   imports' `renameSync` — the property is non-configurable. The hook is
   prefixed `__` and documented as test-only.
3. **Allowlist-test uses `process.env.HOME` override instead of
   `vi.spyOn(os, 'homedir')`** for the same non-configurable-property reason.
   The atomic-write allowlist resolves on module load via `homedir()`, which
   reads `process.env.HOME` on POSIX.
4. **Concurrent-overlap test compiles `atomic-write.ts` to a temp `.mjs` via
   `typescript.transpileModule` so the worker_threads can import it.** Vitest
   workers don't inherit vite-node's loader, so a TS-to-JS bridge was needed.
   The worker uses `crypto.randomUUID()` directly.
5. **`syncAll` resolves `repoRoot` via the worker's `import.meta.url`, walking
   upward looking for `package.json + skills/`.** Falls back to `process.cwd()`
   if URL conversion fails. If the walk does not find a matching directory,
   `result.repoRoot` is populated with a structured AdapterError — `syncAll`
   does not throw. Tests pin this.
