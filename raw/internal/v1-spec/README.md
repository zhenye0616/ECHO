# raw/internal/v1-spec/

Working drafts and supporting docs for V1 spec decisions.

## What goes here

- Iteration drafts of the V1 spec before locking
- Engineering scoping docs (storage schema, MCP tool definitions, hotkey overlay design)
- Sequencing variations considered
- Build estimate spreadsheets

## What doesn't go here

- The locked V1 spec itself → `wiki/product/v1-spec.md`
- Final architectural commitments → `wiki/principles/` (or `wiki/architecture/` if a substrate component)

## Pattern

Free-form drafts. Don't worry about structure here — synthesize into wiki pages once decisions are made.
