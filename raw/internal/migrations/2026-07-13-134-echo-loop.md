## Remediation hardening discovered by adversarial re-audit

- A same-PGID inert sentinel carries the exact launch marker while Git runs.
  If the supervisor dies mid-Git, a successor can authenticate the leaderless
  group by the sentinel plus inherited Git marker and reap it; a real
  supervisor-SIGKILL fixture against a live `git daemon` proves that path.
- Reaping first stops the candidate group, then re-inspects the exact identity.
  If identity changes in that window, only `SIGCONT` is sent—never TERM/KILL or
  a takeover CAS. A deterministic replacement fixture proves the fail-closed
  branch.
- A locally invalid launch binding after takeover uses an exact
  successor-owner/current-launch CAS to leave APPLYING durably, preventing an
  unrecoverable stuck owner without allowing stale mutation.
- Draft-07 validation transports JSON through a mode-0600 temporary file with
  stdin closed and a 30-second bound. This removes an observed Rosetta
  Node-to-arm64 Python stdin-pipe hang without weakening exact-schema
  validation; the transport was exercised repeatedly before the final suite.
