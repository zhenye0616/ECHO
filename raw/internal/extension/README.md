# raw/internal/extension/

Notes and decisions specific to the Chrome extension.

## What goes here

- Extension behavior data (install rates, retention, paid conversion)
- Onboarding question results (cohort distribution from "what do you use AI for?")
- User feedback received via extension support channels
- Decisions about extension features that *don't* belong in V1

## What doesn't go here

- General strategic decisions about the extension's role in V1 → those go in `echo-wiki/sources/extension-funnel-logic.md`
- Validation experiment notes → those go in `raw/internal/interviews/`

## Pattern

One markdown file per decision or data snapshot. Date-prefixed: `2026-04-30-onboarding-question-data.md`
