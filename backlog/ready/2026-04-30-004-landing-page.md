# Landing Page + Paid Waitlist

## What

Public-facing page describing V1, with a $5 paid waitlist deposit as the strongest pre-build wedge signal. Per [[validation-experiments]], conversion rate to paid waitlist is the experiment that validates V1 willingness to pay before V1 exists.

## Why

Three things only this can do:
1. Generate quantitative wedge signal (paid conversion rate) — see [[wedge-vs-thesis-validation]]
2. Build the V1 alpha pool (everyone who pays the $5 is a pre-warmed launch user)
3. Force the team to articulate the value prop publicly (writing the page sharpens thinking)

## Acceptance Criteria

- [ ] Domain registered + deployed (suggest: echo-context.dev or whatever's available)
- [ ] Hero section with brand promise: *"We don't make AI smarter. We make every AI smarter about you."*
- [ ] Subhead: positioning for the dev cohort specifically
- [ ] V1 bundle visualized (5 tool logos: Cursor, Claude Code, GitHub, Slack, web AI)
- [ ] Killer demo description (text version of the GitHub-issue-#234 demo)
- [ ] "Coming October" timeline anchor
- [ ] Two CTAs:
  - **Primary:** "$5 Reserve a Spot" — Stripe Checkout (refundable when V1 ships)
  - **Secondary:** "Free Waitlist" — email only
- [ ] Email + payment go into the same database with cohort tag
- [ ] Privacy-preserving analytics (Plausible / Fathom / self-hosted — not GA)
- [ ] Mobile-responsive
- [ ] Loads in <2s (Lighthouse score >90)

## Constraints

- Brand follows [[brand-promise]] — universal master brand prominent; dev-specific framing layered on
- Per [[felt-not-seen]] — no screenshots of "the app." Show what the user *does better* with ECHO, not ECHO itself
- Honest scope marketing — don't claim more than V1 will actually ship

## Out of Scope (Don't Drift)

- ❌ Full demo gallery videos (placeholder text now; real demos in week 9)
- ❌ Pricing page / tier comparison (single tier; defer)
- ❌ Blog / changelog page (V1.5)
- ❌ Logged-in user dashboard (no users yet to dashboard)
- ❌ Documentation site (V1 launch can be just a landing page)

## Definition of Done

Page is live, accessible, charges $5 successfully via Stripe, captures email, sends confirmation, refundable later. Founder can share URL, see ≥1 paid signup within first week.
