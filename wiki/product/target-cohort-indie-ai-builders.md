# Target Cohort: Indie AI Builders

## Who They Are

Solo developers and small-team founders who are themselves shipping AI tools or AI-enabled products. The collapsed cohort that includes:

- Indie hackers building AI-first products
- Solo dev founders at pre-seed / seed stage
- AI agent builders / MCP server developers
- Cursor power users
- Vibe coders who skew technical
- Pre-YC and YC-batch technical founders

## Why This Cohort for V1

| Dimension | Score | Notes |
|---|---|---|
| Founder-market-fit | **Strong** | The team is one of them — taste = cohort taste |
| Tool stack convergence | **Strong** | ~7 tools cover most of the cohort homogeneously |
| Wallet | **$30–60/mo sustained** | Already pays for Cursor + Claude Code + ChatGPT/Claude |
| Distribution | **Warm** | HN, Cursor Discord, AI Engineer Discord, MCP forums, Latent Space, indie AI Twitter |
| Demo richness | **Highest** | Code + tickets + chats + docs is the densest cross-source context |
| Incumbent threat | **Low** | Devs hate vendor lock-in; cross-provider is welcomed |
| Tar-pit signals | **Few** | Specific cohort, specific demo, defensible position |
| LTV | **High** | $40/mo × 3 years = $1,440 |

See [[three-cohort-comparison]] for the full comparison vs. vibe coders and solo SaaS founders.

## Tool Stack (Defines V1 Bundle)

- **Production:** Cursor + Claude Code
- **Code & tickets:** GitHub
- **Comms:** Slack (or Discord — see notes in [[bundle-decision]])
- **AI:** Claude.ai + ChatGPT + Gemini (web), Claude Desktop, Cursor's built-in
- **Notes:** Notion (deferred to V1.5)

## Where to Find Them

- **Discord servers:** Cursor official, AI Engineer Foundation, Latent Space, Anthropic builders
- **HN:** Show HN, Ask HN, comment threads on AI/tooling posts
- **Twitter/X:** indie AI builder ecosystem (~thousands of active accounts)
- **Newsletters:** Latent Space, Lenny's, Ben's Bites
- **Conferences:** AI Engineer Summit, MCP-related events

## Pain Points That V1 Addresses Directly

1. *"My AI doesn't know about the issue I'm fixing — I have to paste context every time"*
2. *"My code in Cursor doesn't know about the architecture conversation I had with Claude last week"*
3. *"I move between 4 AI tools per day and re-explain myself constantly"*
4. *"My team's Slack discussion of the bug isn't connected to the code I'm fixing"*

The killer demo (*"Solve GitHub issue #234"*) directly addresses all four.

## Validation Plan

Three concurrent experiments — see [[validation-experiments]]:

1. **20 user interviews** in next 3 weeks (talking-to-users discipline)
2. **Landing page + paid waitlist** going up this week (conversion = wedge signal)
3. **Concierge version** for 3–5 hand-picked devs (revealed willingness to pay before product exists)

## Future Cohort Expansion (V2+)

Same architecture, swap production-tool slot:

- **Designers** → Figma + Notion + Slack + Claude + ChatGPT
- **Solo SaaS founders** → Notion + Stripe + Linear + ChatGPT + Twitter
- **Researchers** → Zotero + arXiv + Notion + Claude + GitHub

Each is its own bundle launched as a parallel V2/V3/V4 product, sharing the same substrate.
